# atividades_CienciaDeDados

Este repositório contém exercícios e projetos focados em Ciência de Dados utilizando a linguagem Python. O conteúdo abrange desde os fundamentos da linguagem até a integração com diferentes tipos de estruturas de dados e bancos de dados.

## Conteúdo do Repositório

1. Fundamentos de Programação (Python)
   1.1 Estruturas condicionais (if/else)  
   1.2 Estruturas de repetição (loops)  
   1.3 Manipulação de listas, arrays e coleções  

2. Análise e Visualização de Dados
   2.1 Manipulação e tratamento de datasets  
   2.2 Geração de gráficos para análise exploratória  

3. Coleta de Dados
   3.1 Implementação de Web Scraping para extração de informações de sites  

4. APIs e Persistência de Dados
   4.1 Desenvolvimento e integração de APIs  
   4.2 Modelos de bancos de dados:
       4.2.1 Relacional: Estruturas SQL tradicionais  
       4.2.2 Não-estruturado / Semi-relacional (NoSQL / Documentos)  
       4.2.3 Local: Armazenamento e persistência em ambiente local
